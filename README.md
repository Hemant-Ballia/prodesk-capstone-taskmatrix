# TaskMatrix: Agile Project Management Platform

## High-Level Description
TaskMatrix is an enterprise-grade Agile project management application designed for software engineering teams. Inspired by platforms like Jira and Asana, it streamlines workflow execution through interactive Kanban boards, role-based access control, and real-time activity tracking to prevent technical bottlenecks.

## Designated Track
Fullstack Engineering

## Tech Stack
* **Frontend:** Next.js (React), Tailwind CSS, Shadcn UI, Zustand (State Management), dnd-kit (Drag-and-Drop)
* **Backend:** Node.js, Express.js, Socket.io (Real-time updates)
* **Database:** MongoDB (Mongoose)
* **Authentication:** JWT (JSON Web Tokens) & bcrypt

## Core Features (MVP)
1. **Authentication & RBAC:** Secure JWT-based login with strict role management (Project Manager, Developer).
2. **Interactive Kanban Boards:** Seamless drag-and-drop state management for tasks (To Do, In Progress, In Review, Done).
3. **Task Engine logic:** Create tickets, assign developers, set priority tags (Low, Medium, High), and track deadlines.
4. **Real-Time Activity Sync:** Live dashboard updates via WebSockets when team members update task statuses.
